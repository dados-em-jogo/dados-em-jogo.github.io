# Dados em Jogo

Repositório com pequenos projetos, experimentos e aplicações interativas desenvolvidos para o canal **Dados em Jogo**.

A ideia é transformar conceitos e ideias relacionados a **dados, tecnologia, programação e inteligência artificial** em projetos práticos e, quando possível, interativos.

## 🎮 Sobre o projeto

Este repositório funciona como um hub para os projetos desenvolvidos ao longo dos conteúdos do Dados em Jogo.

Aqui você pode encontrar:

* 📊 Visualizações e explorações de dados
* 🤖 Experimentos com Inteligência Artificial
* 💻 Pequenas aplicações e ferramentas
* 🎲 Projetos interativos
* 🧪 Provas de conceito e experimentos
* 📈 Projetos relacionados a estatística e análise de dados

Cada projeto pode ter seu próprio diretório, código e documentação.
